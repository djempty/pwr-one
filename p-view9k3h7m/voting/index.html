How voting works

Members set the investment mandate by annual vote. The elected Board directs execution within it. Trades are reported to members after the fact. The mandate changes only by member vote. Each member has one vote. The majority of votes cast decides, provided quorum is met. The rationale for each option is shown before you vote.
